# 自定义算子转测验收 Checklist

运行时事实来源是同目录的 `operator_acceptance_checklist.json`。

这个 markdown 文件只保留给人工读者的入口，避免维护两份 checklist 明细导致漂移。
如需调整验收项、源表样例结果或备注要求，请修改 JSON 模板并重新验证报告生成。

## 填写规则

- 每个 checklist 项必须填写明确状态：`是`、`否`、`不涉及`、`需人工确认` 或 `非阻塞备注`。
- `源表样例结果` 只表示原 Excel 中示例行的取值，不是新算子的默认结论。
- 缺少自动化证据但不阻塞的人工项填写 `需人工确认`；显存 ratio 超阈值等参考项填写
  `非阻塞备注`；真正影响自动化验收的缺口才填写 `否`。
